# system names
some system will have proper names instead a simple number   
stars inside the system will have more realistic name that could be tied to the system name

for example let's say that we have this star system with the current algorithm
`System #6` with two stars currently named `6-1` and `6-2`
with the new feature the system could be called `Necklace` and the two stars could be `Necklace-A` and `Necklace-B`

another possibility is that also the stars could have proper names, so the system called `Necklace`
could have stars named `Necklace-A` and `Dust-Ball` 

The list of modern proper names could be extracted from https://en.wikipedia.org/wiki/List_of_proper_names_of_stars
The list should be saved in the feature assets as a csv file

If the number of generated system is greater then the available names a designation will be used, the designation should be similar to what is currently used in astronomy
